## Introduction

This document describes the HTTP API of `stepit-holo serve`, the server that shows on a Looking Glass the quilts other computers upload. It assumes we have read [The Server](../README.md#the-server) in the README.

The server listens on port 8095, e.g. `http://raspberrypi.local:8095`. It documents the same API itself, generated by FastAPI from the code:

| Page | What it is |
|---|---|
| `/docs` | Swagger UI: every route, with a form to try it, e.g. to upload a quilt from the browser. `/` leads there. |
| `/redoc` | The same, as one page to read. |
| `/openapi.json` | The OpenAPI 3 schema, to generate a client. |

Requests and answers are JSON, except the upload, a multipart form, and the quilt read back, an image. There is no authentication.

## The Routes

| Method | Path | What it does |
|---|---|---|
| `POST` | `/quilt` | Shows a quilt, in place of the one before. |
| `GET` | `/quilt` | The quilt shown, as it was uploaded. |
| `DELETE` | `/quilt` | Forgets the quilt, and shows black. |
| `POST` | `/numbers` | Shows the test quilt of numbered views. |
| `GET` | `/status` | The screen, the Looking Glass, and the quilt with whether it is shown. |
| `GET` | `/calibration` | The Looking Glass's calibration. |

There is one quilt at a time: the last one uploaded. The server keeps it on disk, and shows it again after a restart.

## Show a Quilt

```
POST /quilt
Content-Type: multipart/form-data
```

The server reads the image, interleaves it for the Looking Glass with the calibration on the display's drive, and shows it full-screen. It answers once the quilt is on the screen: about 0.4 seconds for a 3360 x 3360 JPEG on a PC, several times that on a Raspberry Pi. The first quilt of a layout and size takes longer, while the server works out the table of the interleaving, about a third of a second on a PC, then keeps it on disk.

### The Fields

| Field | Type | Default | What it is |
|---|---|---|---|
| `file` | file | required | The quilt: a PNG, a JPEG, or any image Pillow reads. Its name gives the layout, e.g. `wasp_qs8x6a0.75.jpg`. |
| `columns` | integer, 1 or more | from the name | The columns of views, when the name does not say. With `rows`, or not at all. |
| `rows` | integer, 1 or more | from the name | The rows of views, when the name does not say. |
| `reverse` | boolean | `false` | Shows the views in the other order, when the depth looks inside out. |

The layout in a name is Looking Glass's own: `_qs8x6a0.75` is 8 columns, 6 rows, views of aspect 0.75. A Portrait's quilt is usually 8 x 6 views, view 0 at the bottom left, rows from the bottom up.

### The Answers

| Status | When | Body |
|---|---|---|
| `200` | The quilt is on the Looking Glass. | The [quilt](#the-quilt). |
| `400` | Not an image, or no layout in the name and none given, or only one of `columns` and `rows`. | An [error](#errors). The quilt before stays. |
| `422` | A field of the wrong type, e.g. `columns=eight`, or no `file`. | FastAPI's list of the fields in error. |
| `503` | The quilt is good, but cannot be shown yet: no Looking Glass found, or no screen of its size. | An [error](#errors). The quilt is kept, and shown as soon as it can be. |

A `503` is not a failure to retry: the server tries again by itself every 5 seconds, until the quilt is shown or another replaces it. `GET /status` says when it is shown.

#### The Quilt

```json
{
  "name": "wasp_qs8x6a0.75.jpg",
  "columns": 8,
  "rows": 6,
  "reverse": false,
  "width": 3360,
  "height": 3360,
  "uploaded": "2026-10-09T10:07:27+00:00",
  "shown": true,
  "shown_on": "HDMI-A-1 of /dev/dri/card1, 1536 x 2048",
  "error": null
}
```

| Field | What it is |
|---|---|
| `name` | The file's name, as uploaded, or `numbers` for the test quilt. |
| `columns`, `rows` | The layout. |
| `reverse` | Whether the views are shown in the other order. |
| `width`, `height` | The quilt's size, in pixels. |
| `uploaded` | When it was uploaded, in UTC, ISO 8601. |
| `shown` | Whether it is on the Looking Glass now. |
| `shown_on` | Where: the screen through DRM/KMS, e.g. `HDMI-A-1 of /dev/dri/card1, 1536 x 2048`, or the desktop's monitor, e.g. `the monitor at 3840, 0, 1536 x 2048`. `null` when it is not shown. |
| `error` | Why it is not shown yet, or `null`. |

## Read the Quilt Back

```
GET /quilt
```

Answers the quilt, as it was uploaded, with its type, e.g. `image/jpeg`, and its name in `Content-Disposition`; the test quilt as a PNG. `404` when there is no quilt.

```bash
curl -OJ http://raspberrypi.local:8095/quilt
```

## Remove the Quilt

```
DELETE /quilt
```

Forgets the quilt, on disk too, and shows black on the Looking Glass. Answers `204`, with no body. Through DRM/KMS, the server keeps the screen, black, until it stops; on a desktop, it closes its window.

## Show the Test Quilt

```
POST /numbers
POST /numbers?reverse=true
```

Shows the test quilt of `stepit-holo numbers`: 48 views, each showing its number on a colour of its own. Through the lenses, one number fills the screen, and changes in order as we move sideways; a mix of numbers means that the calibration is wrong. Answers as [Show a Quilt](#the-answers), with `name` `numbers`.

## The Status

```
GET /status
```

```json
{
  "version": "0.1.0",
  "screen": "drm",
  "looking_glass": {"serial": "LKG-PORT-00671", "width": 1536, "height": 2048},
  "calibration_error": null,
  "quilt": {"name": "wasp_qs8x6a0.75.jpg", "shown": true, "...": "as in Show a Quilt"}
}
```

| Field | What it is |
|---|---|
| `version` | StepIt Holo's version. |
| `screen` | `drm`, straight to the screen, or `desktop`, a full-screen window. |
| `looking_glass` | The Looking Glass's serial number and screen size, once its calibration has been read, at the first quilt; `null` before. |
| `calibration_error` | Why the calibration could not be read, e.g. `no Looking Glass found: ...`, or `null`. |
| `quilt` | The [quilt](#the-quilt), or `null` when there is none. |

## The Calibration

```
GET /calibration
```

The values the interleaving derives from the Looking Glass's `visual.json`, as `stepit-holo calibration` prints them; [The Calibration](ARCHITECTURE.md#the-calibration) explains each. `503` when the calibration cannot be read.

```json
{
  "serial": "LKG-PORT-00671",
  "width": 1536,
  "height": 2048,
  "pitch": 246.91001751815048,
  "tilt": -0.18618341023468643,
  "center": 0.7432299004945404,
  "subp": 0.00021701388888888888,
  "inverted": true
}
```

## Errors

Every error but `422` has the same body, with what went wrong and what to check:

```json
{"detail": "no Looking Glass found: no /media/*/*/LKG_calibration/visual.json or /run/media/*/*/LKG_calibration/visual.json. Is its USB cable plugged in, with a cable that carries data? The quilt is kept, and shown as soon as it can be."}
```

| Status | Meaning |
|---|---|
| `400` | The request cannot work, whatever the Looking Glass: not an image, no layout. |
| `404` | Nothing to give: no quilt. |
| `422` | A field is missing or of the wrong type, in FastAPI's own format: `{"detail": [{"loc": [...], "msg": ..., "type": ...}]}`. |
| `503` | The Looking Glass is not ready: no calibration, no screen of its size, or the screen is held by a desktop. See [Troubleshooting](../README.md#troubleshooting). |

## Clients

### curl

```bash
# Show a quilt whose name gives the layout.
curl -F file=@wasp_qs8x6a0.75.jpg http://raspberrypi.local:8095/quilt

# Show a quilt whose name does not, with its views in the other order.
curl -F file=@quilt.png -F columns=8 -F rows=6 -F reverse=true http://raspberrypi.local:8095/quilt

# What is shown.
curl http://raspberrypi.local:8095/status

# Black.
curl -X DELETE http://raspberrypi.local:8095/quilt
```

`curl --fail-with-body` makes a `4xx` or `5xx` an error of the command, with the message, for a script.

### Python

With `requests`:

```python
from pathlib import Path

import requests

SERVER = "http://raspberrypi.local:8095"


def show(quilt, columns=None, rows=None, reverse=False):
    """Shows a quilt on the Looking Glass. Returns the server's answer; raises if it cannot be shown."""
    fields = {"reverse": str(reverse).lower()}
    if columns and rows:
        fields.update(columns=str(columns), rows=str(rows))
    with open(quilt, "rb") as file:
        response = requests.post(f"{SERVER}/quilt", files={"file": (Path(quilt).name, file)}, data=fields,
                                 timeout=60)
    if response.status_code == 503:
        # Kept: the server shows it as soon as the Looking Glass is there.
        raise RuntimeError(response.json()["detail"])
    response.raise_for_status()
    return response.json()
```

The timeout leaves room for the first quilt of a layout on a Raspberry Pi, which works out its table first.
