# The Web Page's Screenshot

Pull request [#14](https://github.com/kineticsystem/holo-pi/pull/14), branch `web-page-screenshot`.

## Goal

Show the web page as it is in the README's screenshot, `docs/images/web-page.png`: the boxes to tick of #9, the rows without a play button of #12, the upload with only a layout of #13, and the quilts of #11, without `spheres`.

## Decisions

**Taken from the real Pi, with the repo's quilts only.** The four scenes and the helix quilt were uploaded to the Pi under their names, and the helix video played: the frame rate, the decoder and the free space are the Pi's. The Pi's library holds other media too, which a public README should not show, so the page ran on a computer, through a proxy that listed only those five. The uploads went once the picture was taken.

**The same size as before.** 1000 x 603, rendered at twice the resolution in a window 1360 pixels wide and scaled down, so that the table fits and the text stays sharp.
